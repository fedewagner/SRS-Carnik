# AGENTS.md

Las instrucciones para agentes de código (Codex, Cursor, Claude Code y otros) viven en [`CLAUDE.md`](CLAUDE.md). Este fichero existe para que las herramientas que buscan `AGENTS.md` las encuentren; si los dos difieren, manda `CLAUDE.md`.

Las skills y comandos de OpenSpec se versionan en `.claude/`. Para otras herramientas, `openspec init` genera sus copias localmente.
